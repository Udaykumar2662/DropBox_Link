Project: Dropbox Link Xtractor (Python, Streamlit, Dropbox API)

Summary:
Designed and developed a robust web-based tool, “Dropbox Link Xtractor,” leveraging Python, Streamlit, and the Dropbox API to automate the process of extracting, consolidating, and exporting file links from large, nested Dropbox folder structures. The application enables users to generate shareable links for thousands of files (images, PDFs, etc.) across hundreds of subfolders, then export this data into a ready-to-use Excel sheet—all through an intuitive web interface.

Key Features & Responsibilities:

Built a scalable app with Streamlit to allow colleagues and management to extract Dropbox file URLs on demand via any browser.

Integrated Dropbox API for secure folder access, file enumeration, and link generation, across multi-level folder architectures.

Automated the end-to-end workflow: API key authentication, folder/file type selection, robust recursive file search, and link retrieval (including direct and embed links).

Implemented detailed error handling for expired/invalid tokens and access controls, enhancing end-user experience and support.

Enabled Excel export of results (with folder names, subfolder names, file names, sharing links, and embed links) for seamless reporting and sharing.

Tuned for high performance so that very large data sets (1,000+ folders, 10,000+ files) could be processed in a single run.

Facilitated handover, training, and troubleshooting for colleagues, with step-by-step guides and documentation.

Delivered a no-manual-intervention solution, saving >90% effort compared to previous manual link collection methods.

Tech Stack:
Python, Streamlit, Dropbox API, Pandas, Excel, GitHub

Impact:
Streamlined data management for large projects, eliminated repetitive manual tasks, and demonstrated initiative in digital process automation.
